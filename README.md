# Time Stranger Mod Studio

A Windows editor for *Digimon Story: Time Stranger*. Create playable Digimon, edit skills and evolutions, and export PC mods for Reloaded II.

## Quick start

1. Open **Time Stranger Mod Studio.cmd**. Use **Configure Paths** to select your extracted PC game assets and Reloaded II Mods folder.
2. To add a Digimon, choose **Create New → Select Template**. To edit an existing mod, load its folder.
3. For portraits or dot sprites, open **Time Stranger Art Studio.cmd**.
